[Feature: Custom Timestamp]
- Preset time formats (HH:mm a, HH:mm:ss, HH:mm:ss.SSS, h:mm:ss a, h:mm:ss.SSS a)
- Custom format patterns supporting date and time
- Modify timestamp text with ${t} variable
- Live preview for custom patterns and text templates

[Feature: Config Mode]
- Universal mode for sharing one configuration across all supported target apps.
- Target App Specific mode for independent WhatsApp and WhatsApp Business preferences.
- On first use, a target app inherits the current universal preferences as its starting configuration.
- Existing target-app values are preserved when switching between universal and target-specific modes.
- Newly scoped or installed target apps inherit universal values without pre-creating keys for every app.
- Switching target apps in the settings UI refreshes preference controls while preserving the current tab and scroll position.
